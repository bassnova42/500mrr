每年年底，Hacker News 都会有人发帖问：*“Those making $500/month on side projects — show and tell”*。几百位独立开发者在下面晒出自己的小生意：一个 Chrome 插件、一个纸牌网站、一份周刊、一个卖给医院的游戏机管理系统……

问题是，这些帖子散落在 6 年里，大部分是英文长评论，链接也一年年失效。**500MRR 把它们整理成了一本可以逛、可以搜、可以对照现状的图鉴。**

## 连续多年出现的“常青”项目

- **OnlineOrNot**（2021→2025）：每天上班前写2小时，从 $300/月做到 2022 年起稳定超过 $500；策略是在红海里活得比对手久。
- **Hacker Newsletter**（2021、2024、2025）：HN 精选周刊，已做15年，靠赞助。
- **Filestash**（2021、2024、2025）：开源文件管理器，靠企业定制、插件和支持收费。
- **Escape Team**（2021→2025）：打印式密室逃脱 App，5年没加新关卡，收入仍从 $800 涨到约 $1k/月。
- **5/3/1 App**、**ChessCraft**、**BudgetSheet**、**webtoapp.design**、**Stock Events**、**Canine**、**Vlad.studio**、**ScreenMemory**：都至少出现过两次。

## 帖子里反复出现的规律

1. **先解决自己的问题。** 绝大多数项目起点都是“我自己需要”（SmoothTrack、DedupX、Reminder Sync、Lightnote…）。
2. **借平台的流量。** Etsy、App Store、Chrome 网上应用店、Shopify / Slack / Figma / Obsidian / Anki 插件市场、RapidAPI、Steam，都帮那些“不会营销”的开发者拿到了第一批用户。
3. **SEO 和长尾很耐用。** 数独站从 2005 年起月入约 $1k，The Greatest Books 从 2008 年做到 $2k/月，Lightnote 上过一次 HN 首页后稳定了8年。
4. **定价比想象的重要。** 改了定价后从 $5/天涨到 $50/天（That's Ex Quiz）；“随手加个付费墙就有人买”（Happybara）；加 PayPal 后收入翻倍（Lightnote）。
5. **一次性买断也能撑起 $500/月。** PDF Scanner、TechniCalc、Video Hub App、JustFax 都是买断制。
6. **AI 浪潮。** 2024–2025 年大量出现 AI 套壳和 AI 工具，其中收入最高的往往在灰色地带（面试作弊、NSFW）。
7. **非软件副业不少。** 二手转卖、3D 打印、激光切割、散养鸡蛋、园林绿化、晚宴俱乐部（2025 年营收 $126k）、Airbnb 等。
8. **幸存者偏差。** 帖子里也有人提醒：发帖的都是成功的人；还有人分享了收入归零或主动关停的经历（HSK Tests、月入 $5k 的工具关停、Olly 从 $5k 掉到 $500）。

### 关于数据

只收录帖子里的**一级评论**中真正展示了项目或副业的内容，玩笑、元讨论和纯理财（买指数基金、炒期权等）已剔除。收入全部是作者**自述**，没有核实；网站状态是程序自动检查的，可能有误判。

- 完整表格（Excel / Numbers 可直接打开）：[projects.csv](projects.csv)
- 原始数据：`data/raw/*.json`（HN Algolia API）、`data/*.txt`（一级评论纯文本）
- 中文简介和盈利方式：`data/details.psv`
- 重新生成网站和本文件：`python3 scripts/build.py`；重新截图：`node tools/capture.js`；重做头图：`node tools/banner.js`

## Cloudflare 部署

网站部署在 Cloudflare Pages：https://500mrr.rokoai.fun （备用地址 https://500mrr.pages.dev ）。改完数据后运行 `python3 scripts/build.py`，再用 cf-deploy 部署 `site/` 文件夹。

```cf-deploy
{
  "token_env": "CF_TOKEN_BA",
  "account_id": "1c29ea2a8e89fa7bb682b7019105e563",
  "worker": false,
  "pages": [{ "project": "500mrr", "dir": "site", "branch": "main" }],
  "verify": [
    { "url": "https://500mrr.rokoai.fun/", "contains": "HN 月入 $500 副业名录" },
    { "url": "https://500mrr.pages.dev/", "contains": "HN 月入 $500 副业名录" }
  ]
}
```
