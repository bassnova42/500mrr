简介

inlets 是一个可自托管的 HTTP/TCP 隧道工具，类似 ngrok。作者在一家禁止 ngrok 和 SSH 的大公司工作时为了接收 webhook 做的，原生支持容器和 Kubernetes。开源版很受欢迎但赞助很少，于是改为商业授权，并仿照 JetBrains 加了允许商用的个人版和月付选项，个人用户明显增加。作者还靠 GitHub Sponsors 写付费周报。

怎么挣钱

商业授权：企业按年付，个人按月订阅；另有托管云服务。
