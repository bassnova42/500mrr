简介

Approximated 帮 SaaS 把用户的自定义域名接到自己的应用上：一个 API 自动处理 SSL 证书和验证，专用反向代理集群和任播 IP 让用户可以把根域名直接指过来。作者刚有了孩子，没时间营销，但已有数万个域名在用。

怎么挣钱

按域名数量分档的月度订阅，也提供自托管版本。
