简介

作者为了有孩子后在家工作，从 Web 外包公司辞职，在照顾新生儿的空余时间用 Django 做了几个常见的 API：IP 定位 API（附带额外数据）和汇率换算 API。她不擅长营销，就靠 RapidAPI 等市场慢慢积累声誉和用户，利润每月 $1,000–1,800。

怎么挣钱

免费 API key + 按调用量分档订阅（官网 Stripe + RapidAPI）。
