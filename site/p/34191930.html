简介

Mailsac 是给 QA 和开发团队用的临时测试邮箱：任何 @mailsac.com 的地址无需注册就能收信，另有私有收件箱、自定义域名和 REST API，方便自动化测试邮件发送。作者已经做了 10 年以上，从 Node.js + MongoDB 发展到 Go + Postgres。

怎么挣钱

免费公共邮箱引流，私有邮箱、自定义域名和 API 额度按月订阅。
