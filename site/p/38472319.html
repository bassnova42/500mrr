简介

Refined GitHub 是一个精简 GitHub 界面、加入大量实用功能的浏览器扩展。作者原本只是喜欢用，后来大量贡献并成为维护者好几年。每月从 GitHub Sponsors 收到约 $500，作者说远不够付出的时间，但这份工作让他在 GitHub 上的其他工作更愉快。
