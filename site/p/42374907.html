简介

Mockoon 是一个开源的 API Mock 工具，帮开发者快速模拟接口。作者 2017 年业余开始做，三年前开始全职，并推出云服务让项目可持续，加上捐赠。收入增长慢但稳定，作者开始能靠它生活，也保证了开源的未来。
