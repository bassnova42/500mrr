简介

作者有两个相关项目，各自平均每月略超 $500：Sportsbook API 用一个 API 获取多家美国体育博彩公司的赔率；Odds Assist Pro 是赔率扫描工具，显示当前赔率和套利、正期望值等机会，最初只是作者用来检查 API 数据的界面。API 收入稳定缓慢增长，Pro 主要靠推荐和促销，大赛期间有高峰。

怎么挣钱

API 按月订阅 + 工具会员订阅。
